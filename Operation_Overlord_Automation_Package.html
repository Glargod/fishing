Operation Overlord

Full sequential objective system, progressive vehicle unlocks, bunker mutators, and win conditions — ready to drop into UEFN.

0 Quick Start

  1. Open your island in UEFN.
  2. Create a new Verse file named OperationOverlord_GameManager.verse.
  3. Paste the Game Manager code from Section 1.
  4. Place the devices listed in Section 2 and assign them to the matching @editable fields on the manager device.
  5. Build Verse → Push Changes → Test.

The manager handles sequential unlocks, vehicle enabling, and win conditions automatically. You just wire the devices once.

1 Core Game Manager (Verse)

This is the brain. It drives the entire D-Day flow: Beachhead → Bunker Complex → Crossroads → Command Post.

using { /Fortnite.com/Devices }
using { /Fortnite.com/Characters }
using { /Fortnite.com/Game }
using { /Fortnite.com/Playspaces }
using { /Verse.org/Simulation }
using { /UnrealEngine.com/Temporary/Diagnostics }
using { /UnrealEngine.com/Temporary/SpatialMath }

# ============================================================
# OPERATION OVERLORD - Full Sequential War Manager
# Allies (Team 1) must capture all 4 objectives in order.
# Axis (Team 2) win if the timer expires.
# ============================================================

OperationOverlord_GameManager := class(creative_device):

    # ----- Objective Capture Areas (sequential) -----
    @editable Beachhead_Capture : capture_area_device = capture_area_device{}
    @editable BunkerComplex_Capture : capture_area_device = capture_area_device{}
    @editable Crossroads_Capture : capture_area_device = capture_area_device{}
    @editable CommandPost_Capture : capture_area_device = capture_area_device{}

    # ----- Vehicle Spawners -----
    @editable AlliedLandingCraft : []vehicle_spawner_device = array{}          # Always available
    @editable AlliedSupportVehicles : []vehicle_spawner_device = array{}      # Unlock after Beachhead
    @editable AxisHeavyTanks : []vehicle_spawner_device = array{}              # Always available for Axis
    @editable AxisLightVehicles : []vehicle_spawner_device = array{}
    @editable LateGameSharedTanks : []vehicle_spawner_device = array{}         # Unlock after Bunker Complex

    # ----- Mutator Zones (bunker damage boost) -----
    @editable BunkerMutatorZones : []mutator_zone_device = array{}

    # ----- Team Settings / Win -----
    @editable RoundTimer : timer_device = timer_device{}
    @editable AlliesTeamSettings : team_settings_and_inventory_device = team_settings_and_inventory_device{}
    @editable AxisTeamSettings : team_settings_and_inventory_device = team_settings_and_inventory_device{}

    # ----- Accolades (optional but recommended) -----
    @editable BeachLandingAccolade : accolades_device = accolades_device{}
    @editable ObjectiveCaptureAccolade : accolades_device = accolades_device{}
    @editable MultiKillAccolade : accolades_device = accolades_device{}

    # ----- State -----
    var CurrentObjectiveIndex : int = 0
    var BeachheadTaken : logic = false
    var BunkerTaken : logic = false
    var CrossroadsTaken : logic = false
    var CommandPostTaken : logic = false

    OnBegin<override>()<suspends>:void=
        Print("Operation Overlord Game Manager online")

        # Start with only Beachhead active
        DisableAllCapturesExcept(Beachhead_Capture)
        DisableVehicleGroup(AlliedSupportVehicles)
        DisableVehicleGroup(LateGameSharedTanks)

        # Wire sequential captures
        Beachhead_Capture.AgentEntersEvent.Subscribe(OnBeachheadProgress)
        Beachhead_Capture.CapturedEvent.Subscribe(OnBeachheadCaptured)

        BunkerComplex_Capture.CapturedEvent.Subscribe(OnBunkerCaptured)
        Crossroads_Capture.CapturedEvent.Subscribe(OnCrossroadsCaptured)
        CommandPost_Capture.CapturedEvent.Subscribe(OnCommandPostCaptured)

        # Timer = Axis win condition
        RoundTimer.SuccessEvent.Subscribe(OnTimerExpired_AxisWin)

        # Optional: enable bunker mutators immediately
        for (Zone : BunkerMutatorZones):
            Zone.Enable()

    # ============================================================
    # Sequential Capture Logic
    # ============================================================

    OnBeachheadProgress(Agent : agent):void=
        # Optional: award "survived the landing" accolade once
        if (not BeachheadTaken?):
            BeachLandingAccolade.Award(Agent)

    OnBeachheadCaptured(Agent : agent):void=
        if (BeachheadTaken?):
            return
        set BeachheadTaken = true
        set CurrentObjectiveIndex = 1
        Print("BEACHHEAD SECURED - Support vehicles unlocked")

        # Unlock Allied support vehicles
        EnableVehicleGroup(AlliedSupportVehicles)

        # Enable next objective
        BunkerComplex_Capture.Enable()
        ObjectiveCaptureAccolade.Award(Agent)

    OnBunkerCaptured(Agent : agent):void=
        if (BunkerTaken?):
            return
        set BunkerTaken = true
        set CurrentObjectiveIndex = 2
        Print("BUNKER COMPLEX TAKEN - Late game tanks unlocked")

        EnableVehicleGroup(LateGameSharedTanks)
        Crossroads_Capture.Enable()
        ObjectiveCaptureAccolade.Award(Agent)

    OnCrossroadsCaptured(Agent : agent):void=
        if (CrossroadsTaken?):
            return
        set CrossroadsTaken = true
        set CurrentObjectiveIndex = 3
        Print("CROSSROADS SECURED - Final push to the Command Post")

        CommandPost_Capture.Enable()
        ObjectiveCaptureAccolade.Award(Agent)

    OnCommandPostCaptured(Agent : agent):void=
        if (CommandPostTaken?):
            return
        set CommandPostTaken = true
        Print("COMMAND POST CAPTURED - ALLIES WIN")
        ObjectiveCaptureAccolade.Award(Agent)

        # Allies victory
        GetPlayspace().EndGame(EndGameMode.TeamWin, 0)   # Team 1 = Allies (index 0)

    OnTimerExpired_AxisWin():void=
        if (CommandPostTaken?):
            return
        Print("TIMER EXPIRED - AXIS HOLD THE LINE")
        GetPlayspace().EndGame(EndGameMode.TeamWin, 1)   # Team 2 = Axis

    # ============================================================
    # Helpers
    # ============================================================

    DisableAllCapturesExcept(Active : capture_area_device):void=
        Beachhead_Capture.Disable()
        BunkerComplex_Capture.Disable()
        Crossroads_Capture.Disable()
        CommandPost_Capture.Disable()
        Active.Enable()

    EnableVehicleGroup(Group : []vehicle_spawner_device):void=
        for (Spawner : Group):
            Spawner.Enable()

    DisableVehicleGroup(Group : []vehicle_spawner_device):void=
        for (Spawner : Group):
            Spawner.Disable()

Mutator Zones (Bunker Line)

  • Cover the entire cliff / bunker line with mutator zones.
  • Team Filter: Team 2 only
  • Weapon Damage: 1.5×
  • Fire Rate boost: +10–15% if available

This is what makes the Axis machine-gun fire feel properly lethal and suppressing.

3 Recommended Class Loadouts

Allies (Team 1)

  • Assault — SMG + Assault Rifle + Grenades + Medkits
  • Support — Heavy LMG + Ammo
  • Demolition — Rocket Launcher + Explosives
  • Medic — Healing items + SMG

Axis (Team 2)

  • Machine Gunner — Highest fire-rate/damage LMG + extra ammo
  • Bunker Crew — Heavy LMG + grenades
  • Anti-Tank — Rocket / guided missile + explosives
  • Sniper — High-damage long-range rifle

Give Axis higher starting ammo and slightly better defensive weapons.

5 Final Notes for Drew

This package turns the original 10-step manual blueprint into a code-driven sequential war.

  • Only the Beachhead capture starts active.
  • Each objective unlocks the next + the corresponding vehicle group.
  • Timer expiry = Axis victory.
  • All four objectives captured = Allies victory.
  • Bunker mutators make the defensive fire feel properly oppressive.

Wire the devices once, build Verse, and the flow runs itself. The remaining work is mostly terrain, props, and balance tuning.

Note: Some exact device event names or EndGame API details can shift slightly between UEFN versions. If a Subscribe or EndGame call throws a compile error, check the current Verse digest for the exact signature — the overall structure stays the same.
